# Proyecto Final

## Descripción

Este proyecto consta de dos partes principales:

1. Interfaz de usuario: Desarrollada con JavaFX, proporciona una interfaz gráfica de usuario intuitiva para interactuar con la aplicación.

2. Servidor global: Acepta conexiones tanto de clientes de PC como de móviles.

El proyecto se centra en la gestión de propiedades, permitiendo a los usuarios visualizar, añadir y eliminar propiedades. Cada propiedad puede tener múltiples imágenes asociadas.

## Instalación

Para instalar el proyecto, sigue estos pasos:

1. Clona el repositorio en tu máquina local.
2. Importa el proyecto en tu IDE (IntelliJ IDEA 2023.3.4).
3. Asegúrate de tener instalado Java y Maven.
4. Ejecuta `mvn install` para instalar las dependencias.

## Uso

Para ejecutar el proyecto:

1. Inicia el servidor ejecutando la clase `Servidor`.
2. Inicia la interfaz de usuario ejecutando la clase `ClienteApp`.

## Contribución
